- **Briefs 14–30:** the leaked 700,000+ Russian death toll, the Asian market

- **Every story** happened or was first reported on 24 November 2026 in some
  time zone, and each was checked against at least two independent sources.
  Items marked REPORTED are attributed claims, not established facts.

## How it runs

`main.ts` (Node, standard library only) copies the bundled `entry.png` to
`$MAKEFUN_OUTPUT_DIR/entry.png`. The image was drawn offline with Pillow
and shipped in this repository, so both graded runs write identical bytes.
No network is used at any point.

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
